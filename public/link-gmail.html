Two ways to send receipts

Use either one, or both. They send to the same address.

Forward each receipt

No setup

After a ride, open the Tesla receipt email in Gmail, tap Forward, and send it to your address. That's it. Nothing changes in your settings, and it works the same in the Gmail app.

Forward automatically

One-time setup

Set this up once and every new receipt forwards itself. Gmail only has these settings on its website, so do this on a computer.

  1. 1

    Copy your forwarding address

  2. 2

    Add it as a forwarding address in Gmail

    In Gmail, open:

    Settings (gear icon)›, then See all settings›, then Forwarding and POP/IMAP›, then Add a forwarding address

    Paste your address, then click Next and Proceed.

  3. 3

    Enter the confirmation code

    Gmail emails a code to your forwarding address. It appears right here.

    Waiting for Gmail's code. This page checks on its own.

    Your Gmail confirmation code

    Forwarding is confirmed. Receipts are arriving.

    Type the code into Gmail's Confirmation code box under Forwarding and POP/IMAP, then click Verify.

  4. 4

    Create a filter for Tesla receipts

    In Gmail, open:

    Settings (gear icon)›, then See all settings›, then Filters and Blocked Addresses›, then Create a new filter

    In the From box, type . Click Create filter, tick Forward it to, and choose your address. Then click Create filter again.

  5. Done

    Every future receipt now forwards itself. Status on this page turns green when the first one arrives.

Trouble?

Code not showing?

Wait a minute and refresh. Gmail can be slow to send it. If it still hasn't come, check that you pasted the whole address in step 2.

No receipts arriving?

In Gmail settings, check that your forwarding address shows as confirmed under Forwarding and POP/IMAP, and that your filter is still listed under Filters and Blocked Addresses. If you got a new address on this page, the filter needs the new one.

Bring your past rides

Filters only forward new mail, so receipts from before you set this up need one manual pass.

  1. In Gmail, search for to find your old receipts.
  2. Open each receipt and forward it to your address.
  3. Send them one at a time. Gmail's Forward as attachment option bundles emails in a way we can't read.

Not sure if you already sent one? Send it anyway. Duplicates are caught automatically, so a ride is never counted twice.
