  1. Easiest: open a Tesla Robotaxi receipt and forward it to the address above.
  2. To automate it in Gmail: Settings → See all settings → Forwarding and POP/IMAP → Add a forwarding address, and enter the address above.
  3. Gmail sends a confirmation code to that address. It will appear right here — enter it in Gmail to switch forwarding on.
  4. Then create a filter for mail from robotaxi@tesla.com and choose Forward it to your address.
